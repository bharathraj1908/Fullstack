JavaScript Basics

1. What is a Variable?

A variable is a container used to store data values in JavaScript. Example: let x = 10;

2. What is Declaration?

Declaration means creating a variable without assigning a value. Example: let x;

3. What is Initialization?

Initialization means assigning a value to a declared variable. Example: x = 10;

4. 3 Types of Keywords

JavaScript has three main variable keywords:

  • var (old method)
  • let (modern, block scope)
  • const (constant value)

5. Is there a Compiler in JavaScript?

JavaScript does not have a traditional compiler. It is an interpreted language. The JavaScript engine (like Chrome V8) executes the code directly.

6. What is Printing Statements?

Printing statements are used to display output in JavaScript.

  • console.log() → prints in console
  • document.write() → prints on webpage
  • alert() → shows popup message
