Cascading in CSS

Cascading means styles are applied based on priority rules such as specificity, importance, and order. It decides which style will finally appear.

Specificity in CSS

Specificity determines which CSS rule is applied when multiple rules target the same element. ID selectors have higher specificity than classes and tags.

Block vs Inline elements

Block elements take full width (like div, p), while inline elements take only required space (like span, a). Block elements start on a new line.

What is Flexbox?

Flexbox is a powerful layout system used to align and distribute space among items in a container. It simplifies responsive design and alignment.

justify-content vs align-items

justify-content aligns items horizontally along main axis, while align-items aligns vertically along cross axis inside flex containers.

CSS Units

px is fixed size, em is relative to parent font, rem is relative to root font, and % is relative to container size for responsive design.

RGB vs RGBA vs HEX

RGB defines color using red, green, blue. RGBA adds transparency (alpha). HEX uses hexadecimal values for compact color representation.

Position in CSS

Position controls layout flow: static, relative, absolute, fixed, sticky. It helps place elements precisely in a webpage structure.

Z-index

Z-index controls stacking order of elements. Higher values appear above lower values, useful in overlays, modals, and dropdowns.

Transition

Transition allows smooth animation between property changes like color, size, and position, improving user experience.

Transform

Transform is used to rotate, scale, move, or skew elements. It creates dynamic UI effects without affecting layout flow.

Animation

CSS animations use keyframes to create complex motion effects like bouncing, fading, sliding, and looping animations.
